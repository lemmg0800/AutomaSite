# Catálogo Central de Design Systems & Templates

Este catálogo é o índice mestre para o **Agente de IA** selecionar com precisão o melhor design system/template antes de iniciar a criação ou prototipação de qualquer site.

**Total de Design Systems:** 61 (31 Temas Claros + 30 Temas Escuros)

---

## 🧭 Como o Agente Deve Escolher o Template Ideal

1. **Identifique o Nicho e a Intenção do Usuário:** Veja a que setor o negócio pertence (saúde, luxo, automotivo, SaaS, gastronomia, etc.).
2. **Defina a Sensação Visual Desejada:**
   - **Claro / Higiênico / Confiável / Didático:** Use `temas_claros/` (ex: saúde, educação, arquitetura solar, consultorias).
   - **Escuro / Tecnológico / Noturno / Alta Adrenalina / Prestígio:** Use `temas_escuros/` (ex: cibersegurança, cripto, barbearia, eSports, IA).
3. **Localize no Catálogo ou Use a Busca:**
   - Consulte as tabelas abaixo ou execute o script `search.py` para obter recomendações com pontuação de relevância.
4. **Abra os Arquivos de Referência:**
   - Inspecione `design-system.html` para extrair cores, classes Tailwind, tipografia e componentes.
   - Inspecione `index.html` para copiar a estrutura das seções (Hero, Features, Pricing, Testimonials).
